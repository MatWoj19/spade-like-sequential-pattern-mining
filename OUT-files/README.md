# OUT Files

This directory contains output files generated by the SPADE-like sequential pattern mining algorithms.

Each OUT file stores the frequent sequential patterns discovered during an experiment, in the order in which they were found.

For each discovered pattern, the following information is recorded:

- **Pattern length** – Total number of items in the sequential pattern, including repetitions
- **Number of itemsets** – Number of itemsets forming the pattern
- **Tidlist length** – Number of records in the pattern's temporal ID list
- **Support (`sup`)** – Number of input sequences containing the pattern
- **Sequential pattern** – The discovered pattern in its canonical representation

The output files are generated by four algorithm variants:

- **dSPADE** – Depth-First Search (DFS)
- **bSPADE** – Breadth-First Search (BFS)
- **maxLength-dSPADE** – DFS with a maximum pattern length constraint
- **maxLength-bSPADE** – BFS with a maximum pattern length constraint

These files allow the comparison of discovered sequential patterns across different datasets, minimum support thresholds, and algorithm variants.

Although DFS and BFS produce the same set of frequent patterns for equivalent configurations, the order in which patterns are discovered may differ.
