# Datasets

- `small.txt` - a small dataset from the lecture materials.
- `BMSWebView1.txt` - the public BMSWebView1 dataset downloaded from the SPMF repository (`BMS1_spmf.txt`).
- `sign.txt` - the public SIGN dataset downloaded from the SPMF repository.
- `kosarak10k.txt` - the public Kosarak 10k subset downloaded from the SPMF repository.

SPMF files are stored without conversion. The program automatically recognizes the format, where `-1` marks the end of an itemset and `-2` marks the end of a sequence.

Source: https://www.philippe-fournier-viger.com/spmf/index.php?link=datasets.php
